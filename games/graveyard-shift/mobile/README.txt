GRAVEYARD SHIFT - by The Jurn

HOW TO PLAY
Windows: double-click PLAY-GRAVEYARD-SHIFT.bat, or just open index.html in Chrome, Edge or Firefox.
(Optional local server: run  python -m http.server 8000  in this folder and open http://localhost:8000)

CONTROLS: WASD/arrows move, mouse wheel zoom, M map, ESC pause, Enter/Space/Right arrow = next panel.
Weapons fire automatically.
Stage 1: survive the night and beat the Cemetery King. Win it to move on to Stage 2.
Stage 2 (Mega Mart, final stage): beat Produce Horror, Cart Beast and the Meat Manager.
Progress and office upgrades are saved in your browser.

PHONES / TABLETS
Works in mobile browsers. Drag a thumb anywhere to steer (it's an analog stick: drag a little = walk slow).
Top buttons: pause, map, fullscreen (fullscreen works on Android; iPhone Safari doesn't allow it).
Landscape fills the screen; portrait works too, using the space under the game as a thumb pad.
Mobile code lives in mobile.js and only switches on for touch screens; desktop is unchanged.

DEV-ONLY URL SWITCHES (players never see these)
?testbox  - brings back the blue Stage 2 shortcut box near the start
?debug    - debug overlay (F3 / ` toggles it once enabled)
